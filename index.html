agent files

Stay Useful, Stay Quiet

6. Heartbeat Recipes

heartbeat agent

Good heartbeat instructions surface urgent things without turning into a noisy stream of trivia.

heartbeat recipe 
- Check unread urgent email twice a day.
- Check calendar events in the next 24 hours.
- If nothing needs attention, reply HEARTBEAT_OK.

What not to put in heartbeat

Low-value status spam, broad research, non-urgent browsing, or anything you would not want repeated forever.

Decision Trees

10. Troubleshooting Playbooks

debug playbook

Gateway dead

Check health first, inspect diagnostics, then try the safe restart.

gateway safe 
openclaw doctor
openclaw gateway diagnostics export
openclaw gateway restart --safe

Browser stuck

Check browser state, stop it cleanly, then start fresh.

browser debug 
openclaw browser status
openclaw browser stop
openclaw browser start

Agent ignoring context

Review instruction files and tighten the operating rules instead of repeating yourself in chat.

agent context 
AGENTS.md
USER.md
SOUL.md
TOOLS.md

Tasks not finishing

Audit active work, inspect the stuck task, then decide whether to cancel or restart the dependency causing the jam.

tasks audit 
openclaw tasks list --status running
openclaw tasks show <task-id>
openclaw tasks audit
